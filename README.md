# ぱぐっと！— パグ育成ゲーム

1匹のパグに名前をつけ、ごはん・散歩・遊び・お風呂などのお世話をしながら育てる、かわいいブラウザゲームです。画像や外部ライブラリを使わず、HTML・CSS・JavaScriptだけで動きます。

## 遊び方

1. `ゲームを起動.html` をダブルクリックします。
2. パグの名前を入力して「育てる！」を押します。
3. お世話をしてステータス、経験値、コインを増やします。
4. レベルを上げて新しい品物を解放し、ショップで購入します。
5. 「持ち物」から帽子・首輪・洋服を着せ替えられます。

データはブラウザの `localStorage` に自動保存されます。デイリーボーナスは1日1回受け取れます。

### 公園のお散歩モード

育成画面の「お散歩へ行く」を押すと、2Dの公園マップへ移動します。パソコンでは矢印キーまたはWASD、スマートフォンでは画面上の方向ボタンでパグを動かします。マップのコインに触れると既存のコイン残高へ加算され、自動保存されます。「おうちに帰る」で育成画面へ戻れます。

フェーズ1では自宅・住宅街・公園が道と出口で接続されました。マップはパグを追うカメラ、壁・家具・家・木・池・柵の衝突判定に対応しています。

フェーズ2では商店街、ドッグラン、海辺、川沿い、森、駅前、ペットショップ、動物病院、カフェ、夜の公園を追加し、全13エリアになりました。現実の時刻・月・日付を使った昼夜、季節、8種類の天候にも対応しています。

フェーズ3では街に人間NPC5人と10犬種の犬NPCが登場します。近づいて会話すると犬図鑑へ登録され、会話回数と仲良し度が保存されます。仲良し度は「知り合い・友達・仲良し・親友」の4段階です。

## ファイル構成

- `index.html` — ゲーム画面
- `style.css` — レスポンシブデザインとCSS製パグ
- `script.js` — 育成、ショップ、保存などのゲーム処理
- `world.js` — エリア、接続、障害物、衝突判定、追従カメラ
- `npc.js` — 人間・犬NPC、会話範囲、犬友達データ
- `ゲームを起動.html` — ダブルクリック用の入口
- `README.md` — この説明書

## GitHub Pagesで公開する方法

1. このフォルダをGitHubのリポジトリへアップロードします。
2. リポジトリの「Settings」→「Pages」を開きます。
3. 「Deploy from a branch」を選び、`main` ブランチの `/ (root)` を指定して保存します。
4. 数分後に表示されるURLへアクセスします。

バックエンドは不要です。静的サイトを公開できるサービスなら、そのまま配置できます。
